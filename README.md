# 📊 Ecommerce Sales Dashboard

## 🔍 Overview
This project analyzes ecommerce sales performance using Excel and Tableau.

## 🎯 Objective
- Track revenue trends
- Identify top-performing products
- Analyze customer purchasing behavior

## 🛠 Tools Used
- Excel
- Tableau

## 📸 Dashboard Preview
https://drive.google.com/file/d/1phbYFIlNz5Qd4AmklLiHskwfKCbKoDGY/view?usp=drive_link

## 📈 Key Insights
- Seasonal spikes in sales during festive months
- Category Electronic generated highest revenue
- bulk orders contributed significantly to revenue

## 📁 Dataset
Sample ecommerce dataset (cleaned and transformed)

## 🚀 Outcome
Helped identify growth opportunities and improve decision-making.
